Portable by design. Defensive by default.

          
The same auditable Python code runs across Linux, Termux, macOS, and Windows without a runtime package install.

        

        

          
01
Zero dependencies
Built only with the Python standard library and distributed as a single runnable file.

          
02
Cross-platform
Explicit handling for IPv4, IPv6, Windows socket codes, terminals, and portable installers.

          
03
Safe limits
Bounded CIDR expansion, authorization gates, timeouts, throttling, and graceful interruption.

          
04
Useful output
Readable tables plus stable JSON and CSV for defensive automation and evidence collection.

          
05
Banner protection
Service banners are size-limited and sanitized before they can reach your terminal.

          
06
No stealth features
TCP connect scanning only—no spoofing, raw packets, exploitation, or evasion behavior.

Usage examples
Start with a narrow scope. These examples use loopback or private addresses only.

        

          
Scan common web and administration ports on loopback
klahack-portscope -t 127.0.0.1 -p 22,80,443,8000-8010

          
Return the top 20 ports as JSON
klahack-portscope -t localhost --top-ports 20 --json

          
Throttle a private-network audit and save CSV
klahack-portscope -t 192.168.1.0/24 -p 22,80,443 --delay 0.05 --csv --output audit.csv
